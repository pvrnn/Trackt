## Decisions to remember

- **No live provider connectors, no scraping** — catalog data flows only through the central slim catalog (ADR-0001).
- Canonical IDs are frozen forever: namespace `f8d11238-d681-551c-875d-5ac53892f6e7`, key `provider:kind:externalId`.
- `packages/providers` is parked, not deleted; `TMDB_API_KEY` reserved for future enrichment.
- **No full-catalog mirror to self-hosted instances** — search is federated (local + live central), central hits materialize into local `media` on first sight, no background re-sync (ADR-0002).
- **UI primitives are headless-only** — Radix (or similar) for behaviour, never for looks. Do not run `shadcn init` or adopt a pre-styled kit: it rewrites `styles.css` with a parallel `--background`/`--primary` token set, and AURA PRISM's tokens are final per `docs/design/README.md`. Copy a kit's *composition* if useful, then style with our tokens.
- **News is central-only, published by hand, and read live** — no instance news tables, no mirror; every write lands `draft` and only an explicit publish transition exposes it (ADR-0005). Article bodies are untrusted input: render them to elements, never through an HTML string.
- **Relations are stored one direction only** — `prequel`/`source`/`parent` are derived labels, never rows. Every relation read path must filter targets through `canViewMedia`/`visibleMediaSql`, since edges carry no visibility of their own (ADR-0004).
- **The mobile client is instance-agnostic** — no baked-in base URL, no default instance: it opens on a server picker and derives every URL (API, `/api/auth/*`, `/uploads/*`) from the chosen origin. Once a binary is installed, `/api/v1` is a contract with clients that upgrade on the user's schedule, not ours — additive changes only, enums parsed forward-compatibly (ADR-0008).
